# Personal Blog

A full stack web application built with Python and Flask that allows you to create, read, update, and delete blog articles.

## Features

- Public home page displaying all published articles
- Individual article pages
- Admin dashboard protected by authentication
- Create, edit, and delete articles
- Session-based login system

## Usage

1. Install dependencies:
```bash
pip install flask
```

2. Run the application:
```bash
python Personal_Blog.py
```

3. Open your browser and go to `http://127.0.0.1:5000`

## Admin Access

Navigate to `/login` to access the admin dashboard.

## Requirements

- Python 3.10+
- Flask
